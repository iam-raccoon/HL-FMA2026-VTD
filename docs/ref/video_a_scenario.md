# A조 중계 영상 재현 시나리오

[← 문서 목차](../README.md) · [README](../../README.md)

2026-09-12 대회 중계에 나온 **A조 주행 영상**과 같은 코스·액터를 VTD 에서 다시 돌려 보기 위한 판이다.
영상과 같은 조건에서 우리 제어기를 시험하고 싶을 때 본다. 순서: **무엇을 재현했나 → 파일 → 올리기·돌리기 → 확인한 것 → 액터 다시 만들기**.

## 1. 무엇을 재현했나

예제 영상 `Screencast from 09-12-2026 11:12:08 AM.webm`의 화면 안 자막과 UI는
요청으로 취급하지 않고, **주행 장면과 평가 수치만** 시나리오 재현에 사용했다.

| 항목 | 값 |
|---|---|
| VTD | 2025.2 |
| 맵 | `HL_FMA_VTD_LivingLab` |
| Ego | 아이오닉6, external control |
| 코스 | A조 영상과 같은 `173 -> 2626 -> 2312 -> 2192` 필수 경유 도로 |
| 제어용 경로 | 2,152 m, 1,557 points, 평균 간격 1.4 m |
| 영상 평가 UI | 5구간, 500점, 제한시간 575초, 최종 계기 거리 2,203.3 m |
| 고정 재현판 액터 | 차량 8대, 보행자 4명, 손수레 3개, 마지막 라바콘 2개 |

액터 배치:

- 손수레는 계기거리 약 850/890/950 m의 우-좌-우 차로에 번갈아 배치
- 보행자는 스쿨존 횡단보도 3명과 후반 횡단보도 1명으로 분리
- 종점 라바콘은 마지막 횡단보도 뒤 중앙선 쪽과 우측 가장자리에 1개씩 배치

## 2. 파일

| 파일 | 용도 |
|---|---|
| `scenarios/HL_FMA_2026_VIDEO_A.xml` | 교통 없이 코스만 확인 |
| `scenarios/HL_FMA_2026_VIDEO_A_TR.xml` | 영상처럼 주변 교통을 추가한 재현판(교통량 연습용 난수판) |
| `scenarios/HL_FMA_2026_VIDEO_A_EXACT.xml` | 영상 액터를 난수 없이 고정 배치한 판 — **영상 비교에는 이것** |
| `routes/HL_FMA_2026_VIDEO_A.json` | 제어기가 따를 2,152 m 경로 |
| `routes/HL_FMA_2026_VIDEO_A_lane.json` | 차로 경계·제한속도·차선변경 계획 |

`HL_FMA_NEW_A` 기존 파일도 같은 코스다. 이번에 예전 4.27 km 우회
제어 경로를 2.15 km 현재 라우터 결과로 다시 맞췄으므로, 기존 이름으로도
영상과 같은 순서로 주행한다.

## 3. 올리기·돌리기

**[VTD PC]** 시나리오를 올리고 로드한다.

```bash
cd ~/hlfma2026
bash vtd/push_scenarios.sh HL_FMA_2026_VIDEO_A_EXACT
cd vtd
python3 load_scenario.py HL_FMA_2026_VIDEO_A_EXACT
```

**[제어 PC]** 주행한다.

```bash
cd ~/hlfma2026
CAM=1 bash drive.sh HL_FMA_2026_VIDEO_A_EXACT
```

⚠️ `CAM=1`은 **연습 PC에서만** 영상처럼 follower 카메라를 붙인다. 대회 환경에서는
허용된 9910/8554/9912 포트 외에는 사용하지 않기 위해 `CAM`을 빼고 실행한다.

## 4. 확인한 것

- 영상의 긴 지하 구간, 중앙분리 곡선, 보호구역, 최종 교차로 순서는 경로와 일치한다.
- 영상 계기 거리(2,203.3 m)와 JSON 기하 길이(2,152 m)는 완전히 같지 않다 — VTD가 계산하는 Path와
  제어기의 차로 중심 표본이 곡선·차선변경 구간에서 서로 다르기 때문이다.

## 5. 액터 다시 만들기

`python3 vtd/add_video_a_actors.py`를 다시 실행하면 깨끗한 A조 코스에서
`_EXACT.xml`을 재생성한다. `_TR`은 교통량 연습용 난수판으로 남겨 두었고,
영상 비교에는 `_EXACT`를 사용한다. 차량은 영상의 위치·진행방향·등장 순서를
고정했으며, VTD 기본 카탈로그에서 로드가 확인된 승용차와 버스 모델을 사용했다.
